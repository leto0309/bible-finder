# 寻经 Bible Finder 1.1.0

界面优化版本，查询功能与数据不变。

- 修复窄窗口和 Windows 显示缩放下「复制 / 收藏」按钮被挤出、选中经文只显示一行的问题。
- 页头随模式切换（经文查询 / 整章阅读 / 我的收藏），搜索框只在查询时出现，结果区显示更多经文。
- 译本选择移到页头，整章模式也可直接切换；字号调节移到结果标题栏。
- 按钮、示例和下拉框有清晰边界和悬停反馈；已收藏状态以金色标出；选中经文高亮带留白。
- 新增 ↑ / ↓ 切换选中经文；`Ctrl+F` 在任何页面都会回到查询。
- 默认窗口按显示缩放调整大小并居中，不超出屏幕。

解压后退出旧版，替换程序，保留 BibleFinder-data 文件夹即可保留收藏。
