# 寻经 Bible Finder 1.0.0

首个 Windows x64 免安装版。下载 `BibleFinder-1.0.0-windows-x64.zip`，解压后运行 `bible-finder.exe`。

- 完全离线的和合本简体、繁体及 World English Bible，共 93,301 节。
- 中文/英文经文出处、连续经节和同卷跨章范围。
- 关键词搜索，整本/新旧约/单书卷过滤，分页与匹配高亮。
- 整章上下文、书卷章节导航、复制、便携收藏与阅读字号。
- 无账号、无遥测、无付费 API。同一收藏目录仅允许一个窗口，避免覆盖。

系统要求 Windows 10/11 x64；无需管理员或 Python。收藏位于程序旁 `BibleFinder-data/`，更新时保留它。

本版本未做代码签名，随包提供 SHA256 校验。简繁体关键词须与所选译本一致，不支持语义搜索。译本与节数按公开领域上游数据原样保留，详见数据来源文档。
