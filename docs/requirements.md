# 需求与验收

用户要求参考 bibletool.konline.org/query 的圣经查询功能，制作 Windows 免安装软件，并发布 GitHub 公开仓库。用户追加要求先安装到本机试用。新增 API 预算为 0。

1. 下载后双击 EXE 即可用；无 Python、账号、网络依赖。
2. 内置公开领域和合本简体、繁体与 WEB，每个译本完整 66 卷、1,189 章；保留数据来源与哈希。
3. 识别中文简繁书名及简称、英文书名、单节、同章范围、同卷跨章范围、整章；错误章节给出清楚提示。
4. 关键词字面匹配，支持整本/新旧约/单卷范围，结果分页、总数、关键词高亮；英文忽略大小写。
5. 可从结果阅读整章、跨书卷翻章、切换译本、复制带出处的文本、调整字号。
6. 收藏保存在本机；写入原子化，损坏文件不覆盖，同一数据目录禁止多窗口竞争。
7. 查询在工作线程进行，旧查询结果不能覆盖更新的界面状态。
8. 真实全文数据测试、GUI 冒烟测试、factory verify/build/package、独立只读审查、打包后的 EXE 自检与 GUI 检查通过后交付。
9. 本机放置固定便携目录并启动试用；公开仓库只包含源码、公共数据、文档与构建配置，Release 提供 EXE ZIP 和校验值。

不含在线 AI 解经、语音、地图、未授权现代译本或付费服务。新仓库的 AI 云端审查不自动继承工厂配置。

2026-10-23：修复侧栏文字在显示缩放下被裁切；侧栏按实际文字及边距确定宽度，在最小窗口与 100%、125%、150%、200% 字体比例验证完整显示。

## 1.1.0 前端优化（2026-11-12）

用户要求优化界面，并同步更新本机安装的程序。现状问题（125% 缩放实测）：最小窗口下右侧「复制 / 收藏」按钮被挤出界面，选中经文正文只剩一行或完全不可见；标题区占据近一半高度，整章模式只显示一节；下拉箭头过小；次级按钮与面板同色、看不出是按钮；选中高亮包含经文后的空行。

验收条件：

1. 最小窗口按显示缩放等比放大（不超过屏幕）；在该最小窗口及 100% / 125% / 150% / 200% 字体比例下，详情面板的复制、收藏、阅读整章按钮、字号按钮与翻页按钮完整可见，默认字号下选中经文正文至少显示 3 行且可滚动；屏幕不足以容纳设计最小窗口时（如 1920×1080 / 200%）切换紧凑布局，所有操作按钮仍完整可见。
2. 结果区在最小窗口下至少占内容区高度的一半；页头随模式（经文查询 / 整章阅读 / 我的收藏）显示相应标题，搜索框只在查询模式出现，整章模式显示书卷章节导航，译本选择在查询与整章模式都可用。
3. 次级按钮、示例标签、下拉框有可辨识的边界与悬停反馈；已收藏状态有明显区别。
4. 选中经文高亮只覆盖该节，有左右留白；结果中可用 ↑ / ↓ 切换选中经文（输入框和下拉框内不拦截）；`Ctrl+F` 在任何模式回到查询并聚焦。
5. 默认窗口按显示缩放调整并不超过屏幕；所有原有功能、快捷键、GUI 冒烟测试保持通过。
6. 本机 `Documents/Codex/Apps/BibleFinder` 替换为新 EXE，`BibleFinder-data` 收藏文件替换前后 SHA256 一致。
