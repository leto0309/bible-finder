# 安全与隐私

运行时不请求网络、不使用凭据、不上传查询、无遥测。经文库用 SQLite `mode=ro` 打开；搜索参数绑定，`%` / `_` / 反斜线转义为字面字符。查询最多 200 字符，固定分页。

收藏/字号/译本存到 EXE 旁 `BibleFinder-data/settings.json`，支持显式 `--profile-dir`。同一 profile 仅允许一个进程持有 OS 文件锁。写临时文件、flush/fsync 后原子 replace；保存失败显示错误并回滚收藏内存；损坏文件拒绝覆盖。

发布前执行源码与历史机密扫描。工作目录、收藏、EXE、构建缓存不纳入 Git。仅本项目公共数据与源码可发往新公开仓库，工厂凭据与其他项目不属于发布内容。用户已授权本项目公开发布和本机试用；不调用收费 API。

Windows EXE 未代码签名。发布 ZIP 附 SHA256；用户应从该仓库 Releases 下载并校验。更新通过手动替换 EXE，保留数据目录，无自动更新执行路径。
