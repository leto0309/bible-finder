## 1.0.1 侧栏修复（2026-10-23）

固定 170 像素侧栏无法容纳随 DPI 放大的点字号文字。改为按所有侧栏控件的实际请求宽度及水平边距计算侧栏宽度。

- 最小窗口 1000×690、Tk 字体比例对应 100% / 125% / 150% / 200%：旧版在 125% 复现文字裁切；新版所有侧栏标签与按钮的实际尺寸均不小于所需尺寸且在父容器边界内，侧栏宽度分别为 170 / 189 / 217 / 277 像素。
- Factory package 中 verify（39 项测试、ruff、自检）、build、package 全部通过。
- 打包 EXE 自检与 GUI 冒烟测试通过。
- 在本机实际窗口确认左下角两行文字完整，已替换为 1.0.1 并重新打开；替换前后收藏文件 SHA256 一致。
- 保留 1.0.0 历史发布包，1.0.1 作为独立修复版本发布。

## 1.1.0 前端优化（2026-11-12）

改版前在本机 125% 缩放实测：最小窗口下「复制 / 收藏」按钮被挤出详情面板，选中经文正文被压到一行或不可见，整章模式结果区只显示一节。改为按模式切换页头与工具栏、详情面板用 grid 保证正文至少三行，最小窗口与默认窗口按显示缩放调整。

- 新增 `tests/test_ui_layout.py`：在 Tk 字体比例 100% / 125% / 150% / 200% 及对应最小窗口下，查询、整章、收藏三种模式的所有按钮、输入框、下拉框均完整显示在父容器内，详情正文不少于 3 行，结果区不少于内容区 45%；另测模式切换、↑ / ↓ 选择、收藏状态与字号上下限。把最小高度改小后该测试确实失败。
- Factory package：verify（46 项 pytest、compileall、ruff、自检）、build、package 全部通过。
- 打包 EXE `--self-test` 与 `--smoke-test`（新增整章模式页头与 ↑ / ↓ 选择检查）通过。
- 实际窗口截图检查默认与最小窗口下的查询、整章、收藏、错误提示四种状态。
- 本机便携目录替换为 1.1.0，替换前后 `BibleFinder-data/settings.json` SHA256 一致。

已知限制：Tk 不支持中文避头尾规则，窄栏时句末标点偶尔单独换行。
